# ATR Maven Bundle 0.1.1

Initial release of the Buildish ATR Maven Bundle Gradle settings plugin.

- Export selected native Maven publications, including Gradle plugin markers,
  platform/BOM publications, custom artifacts and emitted Gradle module metadata.
- Create Maven Central and Njord repository ZIPs, Njord transportable (`.ntb`)
  archives, and corresponding exploded file layouts. Multiple outputs share one
  preparation step. The transportable format targets Njord 0.9.10.
- Validate retained checksums and complete missing primary-file checksums.
  Require nonempty signatures by default, preserve existing signatures, and
  optionally sign missing files using the root project's Gradle signing setup.
- Produce archives with stable ordering, timestamps and permissions for identical
  prepared bytes and matching build settings.
- Select or exclude projects and publications through the settings extension,
  with explicit command-line and project-property policy overrides.

Plugin ID: `org.buildish.atr-maven-bundle.gradle-plugin`.
Implementation coordinates: `org.buildish.atr-maven-bundle:gradle-plugin:0.1.1`.
Targets Gradle 9.1+ and Java 17+. Native Windows execution is not yet qualified.

The plugin produces local bundles. Remote upload, registry admission and release
orchestration remain separate operations. Signature presence checks do not perform
cryptographic signature verification. Njord transportable output accepts pure
release or pure snapshot selections; mixed selections require a repository layout.
