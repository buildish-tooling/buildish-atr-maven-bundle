# Buildish Maven Bundles for Gradle 0.2.0

Buildish ATR Maven Bundle is now **Buildish Maven Bundles for Gradle**. Use it
to package existing Gradle Maven publications into a local Maven repository ZIP
for Maven Central or an `.ntb` archive for Njord import.

Use Gradle 9.1+ and Java 17+. In `settings.gradle.kts` or `settings.gradle`,
upgrade the version of `org.buildish.atr-maven-bundle.gradle-plugin` to `0.2.0`.
The plugin ID, Maven coordinates, `atrMavenBundle` settings block, and
`atrMavenBundle.*` Gradle properties stay the same.

## Replace task names in your builds

0.2.0 removes the old tasks and aliases. Update your commands as follows.

| 0.1.x task or alias | 0.2.0 task |
| --- | --- |
| `:atrCentralArchive`, `:atrCentral` | `:mavenRepositoryZip` |
| `:atrNjordArchive`, `:atrNjord`, `:atrMavenBundle` | `:mavenRepositoryZip` |
| `:atrCentralFiles`, `:atrNjordFiles` | `:mavenRepositoryFiles` |
| `:atrNjordTransportableArchive`, `:atrNjordTransportable` | `:njordTransportableBundle` |
| `:atrNjordTransportableFiles` | `:njordTransportableFiles` |
| `:prepareAtrMavenBundle` | `:prepareMavenBundle` |

The two plain repository variants now share one ZIP task and one directory task.
For signing on demand, replace
`./gradlew :prepareAtrMavenBundle --sign-missing :atrCentralArchive` with
`./gradlew :prepareMavenBundle --sign-missing :mavenRepositoryZip`.

## Update artifact paths in CI

The paths below assume Gradle’s default build directory. `<bundle>` is
`<baseName>-<bundleVersion>`.

| 0.1.x output | 0.2.0 output |
| --- | --- |
| `build/atr-maven-bundle/central/<bundle>.zip` | `build/maven-bundles/repository/<bundle>.zip` |
| `build/atr-maven-bundle/njord/<bundle>.zip` | `build/maven-bundles/repository/<bundle>.zip` |
| `build/atr-maven-bundle/central/<bundle>/` | `build/maven-bundles/repository/<bundle>/` |
| `build/atr-maven-bundle/njord/<bundle>/` | `build/maven-bundles/repository/<bundle>/` |
| `build/atr-maven-bundle/njord-transportable/<bundle>.ntb` | `build/maven-bundles/njord-transportable/<bundle>.ntb` |
| `build/atr-maven-bundle/njord-transportable/<bundle>/` | `build/maven-bundles/njord-transportable/<bundle>/` |

Update CI artifact collection and upload steps to select the new path explicitly.
Old generated files may still be present after an upgrade. Clean them up when
your build no longer uses them.

See the [released guides](https://buildish.org/components/atr-maven-bundle/latest/)
for the Maven Central and Njord workflows.
